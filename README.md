# mixup: Beyond Empirical Risk Minimization — Reproduction Experiments

Репозиторий с учебным проектом по разбору статьи  
**mixup: Beyond Empirical Risk Minimization**  
Hongyi Zhang et al., ICLR 2018

В рамках индивидуального задания по дисциплине «Архитектура моделей глубокого обучения» воспроизводятся ключевые эксперименты статьи на датасете CIFAR-10 (архитектура PreActResNet-18).

## Структура репозитория

### Скрипты экспериментов
| Файл | Описание |
|------|----------|
| `1.py` | Сравнение ERM и mixup (α=1) на чистых данных, 200 эпох |
| `2.py` | Абляция по гиперпараметру α (0.2, 0.5, 1.0, 2.0, 4.0), 50 эпох |
| `3.py` | Обучение с 20% шумовых меток: ERM vs mixup (α=8), 150 эпох |

### Визуализация
| Файл | Описание |
|------|----------|
| `graph1.py` | График точности по эпохам для эксперимента 1 |
| `graph2.py` | Столбчатая диаграмма для абляции α |
| `graph3.py` | График точности по эпохам для эксперимента 3 (с красной линией на 100-й эпохе) |

### Результаты
| Файл | Описание |
|------|----------|
| `results_exp1.json` | Метрики точности и история обучения эксперимента 1 |
| `results_exp2.json` | Метрики для разных α |
| `results_exp3.json` | История обучения с шумовыми метками |
| `exp1_accuracy.png` | График эксперимента 1 (без отметки lr step) |
| `exp1_accuracy_with_red.png` | График эксперимента 1 (с красной линией lr step) |
| `exp2_ablation.png` | График эксперимента 2 |
| `exp3_noisy.png` | График эксперимента 3 (без отметки lr step) |
| `exp3_noisy_with_red.png` | График эксперимента 3 (с красной линией lr step) |

## Зависимости

Python 3.8+, PyTorch (≥ 1.10, с CUDA при наличии GPU), torchvision, numpy, matplotlib.
Установка:
```bash

pip install -r requirements.txt
```

## Оборудование

Эксперименты проводились локально:

- **CPU:** AMD Ryzen 7 9800X3D  
- **GPU:** NVIDIA GeForce RTX 5080 (Driver 576.88, CUDA 12.9)  
- Среднее время одной эпохи: ~12 секунд при batch size 128.
